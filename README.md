# 📄 PDF 스마트 통합 편집 스튜디오 (PDF All-in-One Editor Studio)

웹 브라우저에서 서버 업로드 없이 **100% 클라이언트 사이드(개인정보 보호)**로 동작하는 강력한 웹 기반 PDF 편집 도구입니다.

🚀 **실행 주소**: https://rdftools.github.io

---

## ✨ 주요 기능 (Key Features)

- **⚡ 파일 선택 즉시 자동 문서 분석**: PDF 파일 선택 시 별도의 시작 버튼 없이 자동으로 문서를 즉시 분석하여 작업 대기 상태로 전환합니다.
- **💧 워터마크 자동 탐지 및 일괄 제거**: 2개 이상 페이지에서 반복 등장하는 텍스트/이미지 워터마크를 자동으로 감지하여 원하는 항목만 한 번에 깔끔하게 지워줍니다.
- **🔗 PDF 파일 순서 재배치 및 병합**: 여러 개의 PDF 파일을 드래그 앤 드롭으로 자유롭게 순서를 변경하고 하나의 완성된 문서로 합쳐서 다운로드합니다.
- **📐 스캔본 기울기 정밀 자동 보정**: 실제 텍스트 좌표(Text Content)의 가로 평행도를 분석하여 비뚤어진 페이지를 스마트하게 수평 보정합니다.
- **🖐️ 직관적인 페이지 편집 (삭제 및 순서 이동)**:
  - 썸네일 그리드를 통해 전체 페이지 구조를 한눈에 파악합니다.
  - 마우스 **드래그 앤 드롭(Drag & Drop)**으로 페이지 위치를 손쉽게 변경하거나 `✕` 버튼으로 삭제할 수 있습니다.
- **🛡️ 영역 직접 마스킹 (화이트아웃)**: 마우스 드래그로 원하는 위치에 가림 박스를 생성하고 크기/위치를 자유롭게 조절할 수 있으며, 현재 마스킹 영역을 **전체 페이지에 일괄 적용**할 수 있습니다.
- **✏️ 텍스트 덮어쓰기**: 크기, 색상, 배경색을 지정할 수 있는 텍스트 상자를 원하는 위치에 얹어 기존 단어나 숫자를 깔끔하게 교체합니다.
- **🖼️ 외부 이미지 추가**: 원본 비율을 자동으로 유지하며 이미지(PNG, JPG 등)를 원하는 위치에 삽입하고 자유롭게 크기를 조절합니다.
- **🔗 클릭 가능한 링크 및 이동 영역 설정**: 특정 위치에 클릭 시 지정 페이지로 이동하거나 외부 웹 URL로 연결되는 이동 핫스팟을 생성합니다.
- **🔑 보안 및 제한 암호 자동 해제**: 열람 및 편집/인쇄 제한 암호가 설정된 PDF를 암호가 제거된 상태로 새롭게 출력합니다.
- **🖼️ 300DPI급 고해상도 출력 지원**: 렌더링 해상도 배율(3.0 Scale) 및 압축 품질(0.98) 상향으로 텍스트 가독성과 이미지 선명도를 극대화하여 다운로드합니다.

---

## 🔒 개인정보 및 보안 (Privacy & Security)

- **100% Client-Side Processing**: 본 서비스는 서버로 어떤 문서도 전송하지 않습니다.
- PDF.js 및 pdf-lib 기술을 활용하여 웹 브라우저 내부 메모리에서만 모든 편집 작업이 처리되므로 중요 민감 문서도 안심하고 편집하실 수 있습니다.

---

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Libraries**:
  - [PDF.js](https://mozilla.github.io/pdf.js/): PDF 렌더링, 페이지 미리보기, 텍스트/이미지 오퍼레이터 좌표 추출 및 정밀 분석
  - [pdf-lib](https://pdf-lib.js.org/): PDF 객체 생성, 텍스트/이미지 오버레이, 주석(Link Annotation) 추가 및 최종 문해상도 저장
