# 📄 PDF 스마트 통합 편집 스튜디오 (PDF All-in-One Editor)

웹 브라우저에서 서버 업로드 없이 100% 클라이언트 사이드(개인정보 보호)로 동작하는 강력한 PDF 편집 도구입니다.

🚀 **실행 주소**: [https://rdftools.github.io](https://rdftools.github.io)

---

## ✨ 주요 기능 (Key Features)

- 💧 **워터마크 자동 탐지 및 일괄 제거**: 2개 이상 페이지에서 반복登場하는 텍스트/이미지 워터마크를 자동으로 감지하여 한 번에 지워줍니다.
- 📐 **스캔본 기울기 정밀 자동 보정**: 픽셀 노이즈 대신 실제 텍스트 좌표(Text Content)의 가로 평행도를 분석하여 0.5° 이상 비뚤어진 페이지만 스마트하게 수평 보정합니다.
- 🗑️ **페이지 선택 삭제**: 특정 범위(예: 1, 3-5)의 페이지를 자유롭게 삭제합니다.
- 🛡️ **영역 직접 마스킹 (화이트아웃)**: 마우스 드래그로 원하는 위치에 민감한 정보 가림 박스를 생성하고 크기/위치를 자유롭게 조절합니다.
- ✏️ **텍스트 덮어쓰기**: 기존 글씨 위에 새로운 텍스트 상자를 얹어 원하는 단어나 숫자로 손쉽게 교체합니다.
- 🔑 **암호 해제**: 보안/열람 암호가 설정된 PDF를 암호가 해제된 버전으로 새롭게 출력합니다.

---

## 🔒 개인정보 및 보안 (Privacy & Security)

- 본 서비스는 **서버로 문서를 전송하지 않습니다.**
- PDF.js 및 pdf-lib 기술을 활용하여 웹 브라우저 내부 메모리에서만 모든 편집 작업이 완벽하게 처리되므로 안심하고 사용하실 수 있습니다.

---

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Libraries**:
  - [PDF.js](https://mozilla.github.io/pdf.js/) - PDF 렌더링 및 텍스트/이미지 좌표 추출
  - [PDF-Lib](https://pdf-lib.js.org/) - PDF 구조 수정 및 최종 문서 재구성/다운로드
